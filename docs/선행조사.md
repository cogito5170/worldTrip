# 선행조사 -- worldtrip (2026-10-01)

**이번에는 선행조사를 하지 못했다.** se_new 규칙("짓기 전에 조사한다")을 못 지켰다는 것을 먼저 적는다.

까닭: 데이터 수집에 세션의 웹 검색 한도(200회)를 다 썼고, 페이지 원문 읽기(WebFetch)는 프록시에 막혔다.
그래서 여행 계획 도구·MCP 서버의 선행 사례를 찾아볼 검색이 남지 않았다.

## 아는 것(기억 -- 출처로 쓰지 않는다)

일정 짜기 앱(Wanderlog, TripIt 류), 항공 검색(Google Flights · Skyscanner), 여행 MCP 서버가 여럿 있을 것이다.
**"없다" 가 아니라 "못 봤다" 다.** 검색 한도가 풀리면 맨 먼저 할 일이다.

## 우리가 다르다고 **주장하려는** 점 (검증 전)

1. 모든 가격에 출처 url · 확인수준 · 날짜가 붙고, 확인수준이 화면 모든 수 옆에 보인다
2. 모르는 비용은 0 이 아니라 '모름' 이고, 그 계획은 거절된다
3. 생성자와 결정적 심판이 따로 돈을 센다(날짜별 재합)
4. 도시는 그래프(직접 연결만), 나라는 트리(연속 방문 · 하한 가지치기)

## 아직 못 지운 가능성
- 위 네 가지를 이미 하는 도구가 있을 수 있다
- 실시간 가격 API 를 붙인 도구는 우리보다 값이 훨씬 정확하다 -- 우리 값은 조사일의 검색 조각이다
